# Proyecto-Paradigmas-
Felipe Velez, Alejandro Castano 
Plataformas Usadas: Visual Studio, Notepad, SWI-Prolog, Haskell, Claude

Haskell: Tomar carpeta del archivo Main.hs y poner en powershell "ghc Main.hs" dejando que el archivo compile, cuando compilado, ejecutar la grafica con .\Main.hs tambien en powershell

Prolog: Tomar carpeta con el archivo "area" y abrir SWI-Prolog, busca "File" y "Consult", ai escoje "area" y el archivo se ejecutara 

En las dos consolas, la imagen se escala para poder verse, en la de haskell, uno tiene que poner la pantalla en fullscreen para verla, mientras en prolog es un poquita mas facil
